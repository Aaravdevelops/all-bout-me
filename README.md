## How I work

- **Read the error, then the source.** Guessing takes longer than scrolling.
- **Small commits, real messages.** `fix: guard undefined user in nav` beats `update`.
- **Copy is fine, understanding is required.** I retype tutorials from memory the second time.
- **Break something on purpose.** Deleting a config line teaches more than a chapter.
- **Done beats perfect** — but only after it runs on someone else's machine.
